# Дерево устройства OrangeFox Recovery для Xiaomi 14 Ultra (`aurora`)

Конфигурация устройства для сборки **OrangeFox Recovery (`fox_14.1`)** для смартфона Xiaomi 14 Ultra (`aurora`) на базе платформы Qualcomm Snapdragon 8 Gen 3 (`SM8650` / `pineapple`). Цель форка на базе https://github.com/mls0x1/android_device_xiaomi_aurora (спасибо за труд) восстановить функционал рекавери, в приоритете дешифрование разделов 


## Статус и возможности (промежуточные)

- [x] Загрузка рекавери, работа дисплея и сенсора
- [x] Работа ADB и MTP (слегка баганое, но юзабельно)
- [ ] Монтирование динамических разделов (`system`, `vendor`, `product`, `odm`, `system_ext`, `vendor_dlkm`) - вручную
- [ ] Прошивка ZIP-архивов и образов разделов (`boot`, `init_boot`, `vendor_boot`, `recovery`) - не проверялось
- [ ] Расшифровка FBE / Metadata (`fox_14.1` - отладка AIDL KeyMint V3) - удалость завести вручную с подменой библиотек. 

## Текущий прогресс
- Пробую перейти на ветку рекавери 16.0 вместо оригинальных для репозитория 12.1
